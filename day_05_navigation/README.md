# Day 05: Navigation & Routing

## 📚 What I Learned
- Multi-screen apps in Flutter
- `Navigator.push()` and `Navigator.pop()`
- Passing data between screens (arguments)
- Named routes vs dynamic routes
- `MaterialPageRoute` for page transitions
- Passing objects between screens

## 🛠 Project: Contacts App
- Home screen with a list of contacts.
- Tap on a contact → navigates to Detail screen.
- Detail screen shows contact's full info.
- Back button returns to Home.
- Add new contact feature (bonus).

## 🎯 Challenges Faced
1. Passing objects (not just strings) between screens.
2. Handling back navigation correctly.
3. Understanding route stack (push vs pushReplacement).
4. Named routes with arguments.
