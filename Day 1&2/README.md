# Day 01 & 02: Dart Basics + Conditions & State

## 📚 What I Learned
- Flutter and Dart environment setup (`flutter doctor`)
- Variables (`int`, `double`, `String`, `bool`)
- Functions and basic logic building
- `if-else` conditions
- `setState()` and the concept of Stateful Widgets
- How the screen rebuilds when state changes

## 🛠 Project: Smart Counter App
- Counter number turns **Red** when it reaches 5.
- Button gets **disabled (grey)** when counter reaches 10.
- Status message is displayed on screen (e.g., "Halfway There!", "Maxed Out!").

## 🎯 Challenges Faced
1. UI doesn't update without `setState()`.
2. To disable a button, `onPressed: null` must be used.
3. Using `if-else` inside `setState` to update multiple variables.
